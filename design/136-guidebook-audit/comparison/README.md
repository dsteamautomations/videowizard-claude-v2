# The free comparison: today's guidebooks against the new ones (2 Nov 2026)

Two writers (the same model as the operator's assistant), each given only one set of guidebooks and the same plan data from VW-12 (the trial film about rat-trap bond walls), wrote three things: the start image prompt for BEAT_01-B1-S1 (a busy building site), the still picture prompt for BEAT_03-B2_sh2 (a finished three-storey house) and the motion brief for the take of BEAT_01-B1-S1. No picture was made; nothing was paid.

## What each writer read

| Step | Today's guidebooks | New guidebooks (documentary-explainer) |
| --- | --- | --- |
| Always open | 7,055 words | 3,430 words |
| Start image | 18,960 words | 2,718 words |
| Still picture | 11,443 words | 3,162 words |
| Take | 9,955 words | 3,261 words |

## What came out

| | Today's guidebooks | New guidebooks |
| --- | --- | --- |
| Start image prompt | 555 words | 620 words |
| Still picture prompt | 392 words | 377 words |
| Motion brief | 206 words | 132 words (says only what moves; leaves the timeline and end state to the server) |
| Rule breaks the server would refuse ("centre", quoted words, settings, model names) | none | none |
| Guidebook rules the writer had to ignore | the race advert's rules (no faces, cold palette, blur cues), the fashion presets, quoted words, timed windows, Camera and Audio lines, handheld, other video models; the start folder held the video model's sheet | none from the guidebooks |
| The look asked for | "a real photograph from a mirrorless camera" | "a frame from tripod documentary video", matching the footage around the gap |

**Reading:** the prompts are of similar quality, because a careful writer can override bad guidebook rules using the map. The new set gets there reading about a fifth of the words, with nothing to override; the old set relied on the writer noticing six kinds of rule it must not follow. A less careful run, or a longer conversation, is where the old set's leftovers would slip into prompts.

## Problems both writers found in VW-12's plan (not in the guidebooks)
- Two brick sizes: 230 × 110 × 75 mm in the world rules, 190 × 90 × 90 mm on the brick element (the 31 Oct brick-size mismatch, design/126 9.3.2). With a 90 × 90 end, a brick on edge looks like a brick laid flat, which the still exists to show.
- The still's plan text says "centred", a word the server refuses.
- The people must wear short sleeves, but the helper's sleeves are long and rolled.
- The still says a face is in frame but names no person.

VW-12 is a trial run to be deleted; these are worth knowing for the next film's plan check.
