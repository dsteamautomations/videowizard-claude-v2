# Describing a person so they stay the same in every picture

A person is described in words, from the footage pictures or the brief, never from a reference photo sent with the call. The sheet and every later picture use the same description. The frame, the background and the style come from the film, not from this file.

## General: every category

### Rules

1. **Look first, then write.** Fill every field below from what the pictures show before writing any prompt. Unsure of a field: ask the operator; never fill in a default.
2. **Only what is there.** An accessory, a mark or a garment the person does not have is never added.
3. **The hair holds its structure.** Name it (loose or tied, where, how fastened, volume, texture) and say it does not change; where a sheet shows a back or side view, check it there.
4. **A crop is a checkable line.** Write it as the last part of the body in frame ("head to mid-thigh"). Add a negative only if a result breaks it.
5. **No name and no real person's likeness** in a prompt.

### The description

| Field | Write | When |
| --- | --- | --- |
| Build | frame and proportions, against something in the shot | always |
| Apparent age | a range ("late forties") | always |
| Skin | undertone, lightness, and where any marks sit | always |
| Face | its shape, and each way it differs from a model's ideal face | face visible |
| Eyes | colour, lid shape | face visible |
| Hair | colour; structure, fastening, position, volume, texture | always |
| Garments | each item: colour, material, fit, layers, how worn and how worn out | always |
| Footwear | type, colour, wear | feet in frame |
| Accessories and carried things | type, colour, where, or "none" | always |
| Posture | stance, the way they hold themselves | always |

### Vague and precise

| Field | Vague | Precise |
| --- | --- | --- |
| Hair | "long hair" | "dark brown long hair tied in a low ponytail, tight and smooth, a black hair tie" |
| Garments | "white top and jeans" | "off-white loose cotton T-shirt, dark blue slim jeans, black leather belt" |
| Skin | "fair skin" | "light warm-toned skin, faint freckles across the nose, a small mole below the left cheekbone" |

### After the sheet

Hair structure, garments and accessories match the description in every view; nothing is added; each view is cropped as written.

## For training-education and documentary-explainer

- The work clothes and their wear, protective kit (or its absence, as the footage shows), the tool in hand and the hand that holds it.

## For advertisement-product

- The product worn or held: which side faces the camera, the label readable where it faces.

## For narrative-story

- The wardrobe for each scene, and what changes in it between scenes.

## For social-ugc

- The phone or camera habit: how the person holds it, where they look.
